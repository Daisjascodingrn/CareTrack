# CareTrack 🩺💻

CareTrack is a fictional healthcare patient management application I am building as a software engineering portfolio project.

The project is to show my entry level skills in simulating real life tools. A simple patient chart system while helping me practice front-end development, JavaScript, data structures, Local Storage, Git/GitHub, and healthcare technology concepts.

> **Note:** CareTrack uses fictional data only. No real patient information is used.

## Current Features

* Add patients
* Store patient name, date of birth, and phone number
* Automatically format phone numbers
* Search patients by name
* Display a dynamic patient count
* Save patient data using Local Storage
* View individual patient profiles
* Navigate between the patient list and patient profiles
* Record blood pressure
* Automatically format blood pressure input
* Classify blood pressure readings into:

  * Normal
  * Elevated
  * Stage 1
  * Stage 2
  * Severe
  * Low
* Save blood pressure information to the patient's record
* Add multiple medications to a patient
* Save medication name, dosage, and frequency
* Reload saved patient information after leaving or refreshing the page
